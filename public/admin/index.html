CMS Publishing Workflow Guide

1. Draft Separation: Any edits made in the tabs are saved as a Draft. The public portal will NEVER see your changes until you explicitly click Publish to Live Site.

2. Discard & Rollback: Made a mistake? Click Discard Draft to reset your draft to the current live version. Previous versions are saved as snapshots.

3. Custom Links: You can link any header tab or footer button to your existing main website (e.g. https://myorganization.com) by managing items in the Navigation & External Links tab.

Keep all added documents and visual settings permanent across Vercel serverless container restarts.

Checking Sync...
💡 Why data resets on Vercel: Vercel runs on ephemeral serverless containers that reboot after ~10–15 minutes of inactivity. When a fresh container starts, it reads only the initial files from Git.
With GitHub Auto-Commit or Browser Auto-Heal, your documents are permanently preserved so nothing is ever lost!

🐙 GitHub Repository Auto-Commit (Recommended)

Whenever you add, edit, or delete documents, the server automatically commits the updated database to your GitHub repository, triggering Vercel to rebuild with your latest documents baked in.

Can also be provided via GITHUB_TOKEN environment variable in your Vercel Project Settings.
